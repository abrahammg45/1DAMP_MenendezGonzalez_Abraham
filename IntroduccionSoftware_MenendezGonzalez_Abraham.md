### ¿QUÉ ES UN PROGRAMA INFORMÁTICO?
- Un **programa informático** es un conjunto de instrucciones escritas en un lenguaje de programación que indican a un ordenador qué tareas debe realizar.


### DIFERENCIA ENTRE CÓDIGO FUENTE, CÓDIGO OBJETO Y CODIGO EJECUTABLE.

* **Código fuente:** es el código escrito por el programador utilizando un lenguaje de programación como C# o Java.

* **Código objeto:** se llama codigo objeto, una vez que nosotros creamos nuestro codigo fuente, un compilador compila nuestro codigo fuente y lo formatea a un formato que el ordenador pueda entener.

* **Código ejecutable:** es el archivo que puede ser ejecutado por el sistema operativo. Por ejemplo un archivo .exe

### ETAPAS DEL DESARROLLO DE SOFTWARE

* **Análisis:** Se investiga profudamente todos los requerimientos para el desarrollo de la tarea/proyecto.
* **Diseño:** Se define cómo estará estructurado el software.
* **Desarrollo:** Se crean las ramas de desarrollo y el codigo necesario para el funcionamiento.
* **Pruebas o QA:** Se comprueba que el programa funciona correctamente y se obliga al sistema a fallar para evitar errores en producción y corregirlos. Lo correcto es hacer las pruebas en un entorno de pruebas completo.
* **Despliegue:** Junto con devops, integramos las ramas de desarrollo con la rama MAIN o MASTER y se sube a PRODUCCIÓN..
* **Mantenimiento:** Con un programa de ticketing junto con cliente, se llevará un control del funcionamiento del aplicativo.
